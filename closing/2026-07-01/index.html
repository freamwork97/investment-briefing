    조건별 탈락 분석

    ❌ 조건 2·3 (거래대금·등락률): 데이터 상충으로 검증 불가

    • 대원전선(006340): 검색 소스마다 등락률(+24.64% vs -2.76%)·거래대금 수치가 상충되어 신뢰 가능한 단일 값 확정 불가. 확정 데이터 없이 매매 리스트에 포함할 수 없음.
    • 금호전기(001210): 거래량 기준 시장 최상위이나, 투자경고종목 지정 + 향후 2거래일 40% 이상 상승 시 거래정지 가능 리스크로 종가매매 대상에서 원천 배제.

    ❌ 조건 3 (등락률 +10~25%): 상한가 종목 초과 사유

    • 보해양조(000890) +29.83%, 금호건설(002990) +29.94% — 모두 상한가 근접·초과로 조건 3 상단(+25%) 초과, 자동 제외.

    ❌ 조건 4·5 (이평선 정배열, 고가 대비 이격): 실시간 데이터 접근 제한

    • KRX·네이버금융 등 국내 시세 사이트 직접 접근 차단(HTTP 403)으로 5일/20일/60일 이동평균선 배열 및 고가 대비 종가 이격도를 신뢰도 있게 확인 불가.
    • 후보 종목(대원전선 등)에 대한 일부 검색 스니펫이 "정배열"을 언급했으나, 조회 시점·기준일이 불명확해 채택 보류.

    결론

    오늘도 매매 없음 (8거래일 연속 관망)

    美 반도체 수출 기대감으로 코스피가 상승 출발했고 전선·건설주 중심의 개별 종목 장세가 이어졌으나, 거래량 상위 종목들이 ①투자경고종목 리스크(금호전기), ②상한가 초과(보해양조·금호건설), ③데이터 상충(대원전선) 등의 사유로 5대 조건을 신뢰도 있게 동시 충족하지 못함. 실시간 국내 시세 데이터 접근 제한으로 이동평균선 정배열·고가 대비 이격 조건은 검증 자체가 불가능한 상황.

    다음 재진입 조건: 신뢰 가능한 실시간 시세 소스 확보 + 투자경고 미지정 종목 중 +10~25% 등락률·정배열·거래대금 500억 이상 동시 충족 종목 재스크리닝

    데이터 검증 노트

    • 데이터 수집 방법: KRX·네이버금융 등 직접 접근 불가(HTTP 403). 서울신문·머니투데이 기사 및 웹 검색 스니펫 기반 추정치 사용.
    • KOSPI 시가 8,591.50(+1.36%, 전일 종가 8,476.48 대비)는 머니투데이 기사 기반이며, 전일(6/30) 브리핑상 종가 8,540.13과 불일치 — 소스 간 수치 상충 확인됨.
    • 대원전선(006340) 등락률·거래대금은 두 소스 간 상충(+24.64%/12,850원 vs -2.76%/11,610원)으로 미채택.
    • 금호전기(001210), 보해양조(000890), 금호건설(002990) 등락률은 서울신문 기사 기준으로 비교적 일관성 확인.
    • 5일/20일/60일 이동평균선 정배열 여부, 고가 대비 종가 이격도(-3% 이내): 실시간 데이터 미확인, 검증 불가로 전 종목 보류 처리.
