    주요 이벤트 (2026-07-20)

    • 코스닥은 18.63포인트(-2.35%) 하락한 773.21로 출발했고, 이후 낙폭이 더 커지며 코스피도 장중 -3.15%(6,605.42)까지 밀리는 등 시장 전반이 약세로 마감(코스피 -4.08%, 코스닥 -5.14%로 검색 확인).
    • WebFetch로 콕스톡(kokstock.com/stock/amount.asp), 네이버금융(finance.naver.com/sise/sise_quant_high.naver) 접속 시도 → 콕스톡 HTTP 403 Forbidden, 네이버금융은 접속 자체 실패. 개별 종목의 거래대금·시가/고가/저가·이동평균선 데이터는 오늘도 확보 불가.
    • WebSearch로 "코스피 코스닥 거래대금 상위 종목 2026년 7월 20일 마감", "코스피 코스닥 마감 지수 2026-07-20" 쿼리 시도 → 지수 수준의 급락 관련 뉴스는 확인됐으나, 개별 종목 단위 거래대금·등락률·이평선 데이터는 검색 결과에 없음.
    • 세션에 연결된 MCP 커넥터는 Slack·GitHub뿐이며, 증권 시세 전용 데이터 소스(KRX, 증권사 API 등)는 여전히 연결되어 있지 않음.

    • 조건 1(가격 1천~10만원)·2(거래대금 500억↑)·3(등락률 +10~25% 또는 시가 대비 종가 10%↑)·4(이평선 정배열)·5(고가 대비 이격 -3% 이내) 중 단 하나도 실제 데이터로 검증하지 못함.
    • 참고로 오늘은 코스피 -4.08%·코스닥 -5.14%의 시장 전반 급락일로, 지수 흐름상으로도 조건 3(강한 상승 탄력)·조건 4(정배열 우상향)를 동시 충족하는 종목이 존재할 가능성 자체가 낮은 장세였음. 다만 이는 지수 동향에 근거한 정황 추정일 뿐, 개별 종목 데이터로 검증된 결론은 아님.
    • 지어낸 수치로 조건 충족 종목을 채우는 대신, 검증 불가 상태를 그대로 보고함.

    결론

    오늘도 매매 없음

    7/20 당일 개별 종목 데이터는 실시간 데이터 접근 제약으로 확인하지 못했음(지수는 뉴스 검색으로 확인). 이 세션 환경에는 실시간 국내 증권 시세를 제공하는 MCP 커넥터가 연결되어 있지 않고, 주요 금융 사이트(네이버·콕스톡)는 WebFetch를 차단하고 있어, 5대 조건 스크리닝 자체가 구조적으로 불가능한 상태가 한 달 가까이 지속되고 있음.

    다음 재진입 조건: 신뢰 가능한 실시간 국내 시세 데이터 소스(증권사 API, KRX Data Marketplace 인증 접근, 또는 전용 증권 데이터 MCP 커넥터) 확보 시 재스크리닝.

    데이터 검증 노트

    • 데이터 수집 방법: WebFetch로 콕스톡(kokstock.com)·네이버금융(finance.naver.com) 접속 시도 → 콕스톡 403 Forbidden, 네이버금융 접속 실패. WebSearch 2개 쿼리로 코스피(-4.08%)·코스닥(-5.14%) 지수 급락은 확인했으나 개별 종목 데이터는 확보하지 못함.
