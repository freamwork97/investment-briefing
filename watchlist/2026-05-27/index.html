    변동성이 크고 강한 모멘텀이 기대되는 종목

    순위 종목 (코드) 전일 종가 기술적 근거
    ① 1순위 한화오션 (042660) ~145,000원 추정 당일 +9.90% 급등 + 전고점(140,600원) 강력 돌파 + 거래량 폭증 동반. 볼린저 상단 돌파 안착 시도. 갭상승 시 눌림목 공략, 양봉 연속 시 모멘텀 추격
    ② 2순위 HD현대중공업 (329180) ~350,000원 추정 당일 +9.41% + 1.78조원 수주 호재 공시 + 조선섹터 리더십. 내일 시초가 양봉 확인 후 진입, 단기 상한가 도전 가능
    ③ 3순위 SK하이닉스 (000660) ~2,800,000원 추정 당일 +6.49%, HBM 실적 기대감 + 목표가 도달 구간, 볼린저 상단 돌파 모멘텀. 변동성 큰 단기 플레이

    📊 국장 스윙 관심주 3선

    5/20일선 골든크로스, ADX 추세, 외인/기관 수급 기반 (3~10일 보유)

    순위 종목 (코드) 수급 근거 기술적 시그널
    ① SK하이닉스 (000660) 외국인 지속 순매수 / DRAM 2026년 영업이익 +78%YoY 전망 / KB증권 목표가 280만원 5일선>20일선 정배열, ADX 강세 추세 유지, 볼린저 상단 돌파. 의미있는 전고점 돌파 + 거래량 동반
    ② 한화오션 (042660) 외국인 2026년 연간 최대 순매수 / LNG선 수주잔고 업계 1위(51.6%) / 미 MASGA 참여 2월 장기 저항선(13만원대) 강력 돌파 후 5일선이 중장기선 상향. 슈퍼트렌드 매수 시그널 구간
    ③ HD한국조선해양 (009540) 기관+외인 조선섹터 동반 수급 / 지주사 저평가 메리트 / 수주 연동 실적 개선 5/20일선 골든크로스 근접, 조선섹터 추세 연동, 의미있는 전고점 돌파 시도 구간

    📌 내일 매매 전략 요약

    • 시초가 공략: 갭 +3% 이내 시 눌림목 대기 → 10시 전후 방향성 확인 후 진입
    • 손절 기준: 전일 저가 이탈 시 즉시 손절 (리스크 관리 최우선)
    • 스윙 진입: 장중 5일선 이탈 없이 양봉 유지 시 분할 매수 추가
